# Tzy OS

一套跑在浏览器里的桌面系统。平板或手机不用安装任何东西、也不用改代理设置，
只要打开平时就在用的在线专栏页面，输入约定的口令，就能进入一个完整的桌面环境：
文件管理、文档编辑、媒体播放、网页浏览器、应用商店、小游戏等都可以随取随用。

断网或电脑暂时不可达时，已经用过的页面依然可以从本地重新打开，桌面上原有的
应用和个人文件都还在。


---

## 能做什么

### 桌面体验

- **锁屏与密码**：首次使用可在锁屏上设置 4 位数字密码；之后可随时修改或关闭。
  密码只保存在本机，用于防止旁人随手翻看。
- **壁纸**：内置多套配色，也可以自己挑两种颜色生成一张渐变壁纸，
  选色时能实时预览，满意后再应用。设置会记住，下次打开还是它。
- **应用与窗口**：应用以窗口方式打开，可拖拽、缩放、最小化、最大化，
  双击标题栏即可铺满屏幕；右下角 Dock 显示当前打开的应用，点一下就能切回去。
- **所有窗口一览**：状态栏「窗口」按钮能把正在运行的应用铺成卡片，
  方便快速切换或一次性关掉。
- **状态栏**：显示时间、网络状态（能否连上电脑），以及回桌面、窗口总览、
  锁屏、返回原页面四个操作。
- **系统信息**：设置页里可以看到当前系统版本与已安装应用清单。

### 内置应用

| 应用 | 用途 |
| --- | --- |
| 文件管理 | 浏览电脑硬盘、离线空间、FTP 与局域网共享；复制、移动、重命名、批量操作、压缩解压、图片预览 |
| 记事本 | 编辑纯文本与 Markdown，可直接保存到任意位置 |
| 文档查看 | 打开 PDF、Word、图片与演示文稿，支持翻页阅读 |
| 媒体播放 | 播放音乐与视频，支持歌单、歌词与后台连续播放 |
| 应用商店 | 浏览、安装、升级、卸载应用包 |
| 网页浏览器 | 在桌面里直接上网，支持收藏夹、历史、下载与文件上传 |
| 智能搜索 | 在文件、应用与网络内容之间统一查找 |
| 计算器 | 日常四则运算 |
| 维护终端 | 排查与修复用：查看系统状态、清理缓存、重建应用、强制刷新、重置设置并保留个人文件 |

### 附加能力

- **小说下载**：内置多个中文书源，可直接搜索、下载并导出整本小说。
- **局域网聊天**：同一网络内的设备之间可以互发消息与文件。
- **应用包**：除内置应用外，可以像装软件一样安装新的应用包，也可以随时卸载。

### 可靠性

- 电脑端服务暂时不可用、页面缓存异常、应用文件损坏时，系统会自行尝试恢复；
  仍然不行时，维护终端提供手动修复手段，无需重装。
- 已经安装的应用和个人文件在重置设置时会保留。

## 快速开始

**目标电脑无需安装任何东西**，解压后即可使用。

1. 解压发布包，右键以管理员身份运行 `install.bat`，按提示选择使用方式
   （让平板连接电脑开的热点，或让平板与电脑处在同一个局域网）。
2. 之后每次使用运行 `start.bat`。
3. 平板上打开平时用的在线专栏页面，按约定方式唤起，输入口令即可进入。

电脑端的设置页面可以调整注入开关、唤起方式、DNS 与端口等选项。

> 详细说明见仓库内的 `BUILD.md`（打包与发布）与 `ARCHITECTURE.md`（结构说明）。

## 系统要求

- 电脑：Windows 7 SP1 / 8.1 / 10 / 11，需要管理员权限。
- 平板/手机：任意现代浏览器即可，推荐使用平板自带浏览器。
